# Administración de Sistemas Gestores de Bases de Datos (ASGBD)

Bienvenido/a al módulo **0377 de Administración de Sistemas Gestores de Bases de Datos (ASGBD)** del ciclo formativo de Grado Superior (ASIX) del IES El Caminàs.

El enfoque del módulo es profesional y práctico: aprenderás a implantar, configurar, proteger, monitorizar y mantener sistemas gestores de bases de datos, aplicando procedimientos propios de un administrador de bases de datos (DBA).

El trabajo se orientará principalmente a los SGBD **PostgreSQL** y **MySQL**, utilizando habitualmente el modelo cliente/servidor y relacionando la teoría con tareas prácticas de administración.

!!! note "Cómo trabajaremos"
    El módulo dispone de **2 horas semanales**. Cada unidad combinará conceptos, ejemplos y actividades prácticas para avanzar paso a paso en la administración de bases de datos. Se priorizarán las tareas esenciales y se ofrecerán pautas para seguir profundizando de forma autónoma.
---
## Objetivos

- Analizar las características de los sistemas gestores de bases de datos y seleccionar el más adecuado para cada necesidad.
- Instalar y configurar sistemas gestores de bases de datos de acuerdo con las especificaciones técnicas y los requisitos de explotación.
- Organizar y administrar la información, las estructuras de almacenamiento y los objetos de las bases de datos.
- Gestionar usuarios, roles y permisos aplicando medidas de seguridad y protección de la información.
- Realizar copias de seguridad, restauraciones y tareas de recuperación ante fallos.
- Monitorizar el funcionamiento de los sistemas gestores de bases de datos y optimizar su rendimiento.
- Elaborar y ejecutar guiones para automatizar tareas habituales de administración.
- Conocer las características y las técnicas de implementación de los sistemas gestores de bases de datos distribuidas.
- Documentar las tareas de administración y aplicar procedimientos de trabajo seguros y ordenados.

---
## Resultados de aprendizaje del módulo 

- **RA1.** Implanta sistemas gestores de bases de datos analizando sus características y ajustándose a los requerimientos del sistema.
- **RA2.** Configura el sistema gestor de bases de datos interpretando las especificaciones técnicas y los requisitos de explotación.
- **RA3.** Organiza y gestiona la información del sistema gestor de bases de datos aplicando técnicas de administración.
- **RA4.** Realiza tareas de monitorización del sistema gestor de bases de datos identificando parámetros y utilizando herramientas de seguimiento.
- **RA5.** Elabora y ejecuta guiones de administración y automatización de tareas identificando las necesidades de gestión del sistema.
- **RA6.** Implementa sistemas gestores de bases de datos distribuidas analizando sus características y las técnicas de distribución.

## Módulo profesional

El módulo profesional **0377: Administración de Sistemas Gestores de Bases de Datos** prepara al alumnado para implantar, configurar, administrar y mantener sistemas gestores de bases de datos, de acuerdo con las necesidades de una organización y con criterios de seguridad, disponibilidad y rendimiento.

De acuerdo con la finalidad del módulo, se espera que el alumnado sea capaz de seleccionar e instalar un SGBD, configurar sus parámetros de funcionamiento, organizar la información, gestionar usuarios y permisos, realizar copias de seguridad y recuperación, monitorizar el sistema y automatizar tareas administrativas. También se introducen las características de los sistemas gestores de bases de datos distribuidas.
