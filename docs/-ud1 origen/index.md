# UD 1: Implantación de un SGBD

Esta unidad presenta la arquitectura de los sistemas gestores de bases de datos y desarrolla la instalación, configuración y uso inicial de PostgreSQL.

## Objetivos

- Comprender los niveles y componentes de un sistema gestor de bases de datos.
- Identificar las funciones principales del administrador de bases de datos.
- Instalar PostgreSQL en un servidor Ubuntu y preparar un cliente.
- Configurar el acceso local y remoto mediante `postgresql.conf` y `pg_hba.conf`.
- Utilizar `psql` y pgAdmin para administrar bases de datos.
- Comprobar la conexión, importar datos y documentar la puesta en marcha.
