En este bloque prepararás servidores Linux en **AWS Academy**, el entorno educativo de Amazon Web Services. Utilizarás instancias EC2 para instalar PostgreSQL y otros servicios de administración de bases de datos.

## Contenidos

- [Introducción a AWS Academy](01-intro-aws.md): Conceptos básicos, grupos de seguridad, pares de claves y acceso a instancias.
- [Servidor Linux en AWS Academy](02-servidor-linux.md): Creación de una instancia EC2 con Ubuntu Server y conexión por SSH.
- [IP Elástica](03-ip-elastica.md): Cómo mantener una dirección IP pública fija en AWS.

## Recursos y seguridad

El laboratorio AWS tiene ciclo de vida: inicia antes de trabajar, detén las instancias al terminar y finaliza el laboratorio para evitar consumir saldo innecesario.

Protege siempre tu par de claves privado y no publiques credenciales en repositorios o capturas.
