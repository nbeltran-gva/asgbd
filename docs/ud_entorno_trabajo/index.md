# Entorno de trabajo

En esta sección configurarás **tres opciones de infraestructura** para administrar PostgreSQL:

## Opciones disponibles

🌐 **AWS Academy**

- Servidores Linux en la nube usando instancias EC2 en **AWS Academy**. 
- Ideal para aprender administración en un entorno cloud.

💻 **Virtual Box**

- Máquinas virtuales con **VirtualBox** en tu equipo. 
- Utiliza la plantilla Ubuntu Server proporcionada en AULES.
- Asigna solo la memoria y CPU necesarias. 
- Conserva instantáneas, pero no sustituyen a las copias de seguridad de entregas.

🐳 **Docker**

- Contenedores **Docker** para un entorno reproducible. 
- Ejecuta PostgreSQL en Docker sin instalaciones directas en tu equipo.
- Para una configuración completa con **pgAdmin** o **DBeaver**, consulta el [Anexo de PostgreSQL con Docker](../ud3/08-anexo-postgresql-docker.md).

---

Elige la opción que mejor se adapte a tu práctica y sigue la guía correspondiente.
