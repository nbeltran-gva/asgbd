- [Creación de máquinas virtuales](03-creacion-vm.md): Importar la OVA del curso o crear una VM nueva.
- [Configuración de red](04-configuracion-red.md): Modos de red, dirección estática con Netplan.
- [Conexión por SSH](05-conexion-ssh.md): Instalar OpenSSH y conectarse desde cliente.
- [P0.1. Comandos básicos Linux](06-comandos-basicos.md): Primeros pasos en la terminal de Ubuntu.

## Recursos

Asigna solo la memoria y CPU necesarias. Conserva instantáneas, pero no sustituyen a las copias de seguridad de entregas.
