# UD 4: Automatización de tareas

## Introducción a la unidad

En esta unidad se estudian las técnicas que permiten automatizar tareas habituales de administración y mantenimiento de bases de datos.

## Índice de contenidos

0. [Introducción a la automatización de tareas](00-introduccion.md)
	* Tareas programadas y planificación.
	* Scripts de administración.
	* Copias de seguridad automatizadas.
	* Mantenimiento periódico de bases de datos.
	* Registro y control de ejecuciones.
	* Gestión de errores y notificaciones.
	* Automatización segura y documentada.

## Objetivos

- Identificar tareas repetitivas que pueden automatizarse.
- Diseñar scripts sencillos de administración.
- Programar copias de seguridad y tareas de mantenimiento.
- Registrar los resultados y errores de cada ejecución.
- Mejorar la eficiencia y la fiabilidad de la administración.

## Criterios de evaluación

Se valorará que las tareas automatizadas sean reproducibles, seguras, documentadas y capaces de informar de sus resultados.
