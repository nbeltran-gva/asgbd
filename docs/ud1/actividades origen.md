# Actividades de implantación

Realiza un documento con explicaciones y capturas que demuestre cada resultado. Trabaja sobre las máquinas virtuales disponibles en Aules y conserva copias de seguridad de los ficheros de configuración modificados.

## Actividades de Implantación e instalación de PostgreSQL

### Actividad 1

Instala la **última versión de PostgreSQL en una Ubuntu Server**. Al tratarse de un servidor, asígnale una IP estática modificando el fichero de Netplan.

### Actividad 2

Instala la última versión de **pgAdmin en una Ubuntu Mate**. Comprueba que el cliente se inicia correctamente y documenta las herramientas disponibles para trabajar con PostgreSQL.

### Actividad 3

Instala la versión web de pgAdmin en Ubuntu Server. Comprueba que se puede acceder a la apli
cación desde un navegador cliente y documenta los requisitos de software utilizados.

### Actividad 4

Instala el cliente `psql` en Ubuntu Mate y comprueba que puede iniciarse. Identifica la versión instalada y verifica que las herramientas cliente necesarias están disponibles en el sistema.
