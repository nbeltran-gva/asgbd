# Actividades recomendadas

## Trabajo práctico

1. Analiza la arquitectura de un SGBD y explica cada uno de sus niveles.
2. Describe los principales componentes del sistema y su función.
3. Compara los distintos modelos de explotación de bases de datos.
4. Explica las tareas principales que realiza un administrador de bases de datos.
