# 0. Introducción

## Introducción a la unidad

En esta unidad se estudian los fundamentos del uso y la administración de un sistema gestor de bases de datos relacional.

## Objetivos

- Comprender la estructura y funcionamiento básico del SGBD.
- Conocer los conceptos de diseño y acceso a los datos.
- Identificar los elementos esenciales para su administración.
