# UD 2: Gestión de un SGBD

Esta unidad desarrolla la gestión de usuarios, bases de datos, copias de seguridad y vistas en PostgreSQL.

## Recorrido de la unidad

1. [Introducción](00-introduccion.md)
2. [Usuarios, roles y permisos](01-usuarios-permisos.md)
3. [Bases de datos, esquemas y tablespaces](02-bases-datos.md)
4. [Copias de seguridad y restauración](03-copias-restauracion.md)
5. [Vistas](04-vistas.md)
6. [Ejercicios](actividades.md)

## Objetivos

- Gestionar roles de usuario y de grupo.
- Asignar y retirar permisos sobre bases de datos, esquemas y tablas.
- Crear bases de datos y organizar sus objetos mediante esquemas y tablespaces.
- Realizar copias de seguridad con `pg_dump` y pgAdmin.
- Restaurar bases de datos y transferir información entre ellas.
- Crear vistas y utilizar las vistas del sistema para consultar metadatos.
