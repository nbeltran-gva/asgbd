# UD 3: Automatización de tareas con PL/pgSQL

Esta unidad introduce la programación procedimental en PostgreSQL para automatizar consultas, tareas de administración y respuestas a cambios en la base de datos.

## Recorrido de la unidad

1. [Introducción](00-introduccion.md)
2. [PL/pgSQL y fundamentos del lenguaje](01-plpgsql-fundamentos.md)
3. [Procedimientos y funciones](02-procedimientos-funciones.md)
4. [Cursores y excepciones](03-cursores-excepciones.md)
5. [Triggers y ejemplos de aplicación](04-triggers-aplicaciones.md)
6. [Actividades](actividades.md)

## Objetivos

- Escribir bloques PL/pgSQL con variables, operadores y estructuras de control.
- Crear y ejecutar procedimientos anónimos, procedimientos almacenados y funciones.
- Recorrer resultados mediante cursores y controlar errores con excepciones.
- Automatizar validaciones y mantenimiento mediante triggers.
- Documentar el código, las pruebas y los resultados de cada ejercicio.
