# UD 2: Configuración de un SGBD

Esta unidad se centra en configurar PostgreSQL después de su instalación, preparar las conexiones y comprobar que el servicio funciona de forma segura y estable.

## Objetivos

- Identificar los archivos principales de configuración de PostgreSQL.
- Configurar conexiones locales y remotas de forma controlada.
- Aplicar y comprobar cambios en el servicio.
- Verificar el acceso desde clientes.
- Interpretar errores y documentar la configuración realizada.
---

## Criterios de trabajo

La unidad desarrolla el RA2: «Configura el sistema gestor de bases de datos interpretando las especificaciones técnicas y los requisitos de explotación».

Se considera que la actividad se ha desarrollado de forma satisfactoria cuando se han cumplido los siguientes criterios:

- a) Se han descrito las condiciones de inicio y parada del sistema gestor.
- b) Se ha seleccionado el motor de base de datos.
- c) Se han asegurado las cuentas de administración.
- d) Se han configurado las herramientas y software cliente del sistema gestor.
- e) Se ha configurado la conectividad en red del sistema gestor.
- f) Se han definido las características por defecto de las bases de datos.
- g) Se han definido los parámetros relativos a las conexiones (tiempos de espera, número máximo de conexiones,
entre otros).
- h) Se ha documentado el proceso de configuración.
---

## Planificación

La unidad se desarrolla en un tiempo estimado de 6 horas, distribuidas entre la explicación de los conceptos fundamentales, la configuración práctica del sistema y la comprobación del correcto funcionamiento de las conexiones y servicios.
