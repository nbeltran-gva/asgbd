# UD 2: Configuración de un SGBD

## Introducción a la unidad

En esta unidad se estudian los parámetros y elementos que permiten adaptar un sistema gestor de bases de datos a las necesidades de una organización.

## Índice de contenidos

0. [Introducción a la configuración de un SGBD](00-introduccion.md)
	* Configuración inicial del servidor.
	* Parámetros de conexión y acceso desde clientes.
	* Creación y configuración de bases de datos.
	* Gestión del almacenamiento y de la memoria.
	* Parámetros básicos de rendimiento.
	* Copias de seguridad y recuperación.
	* Buenas prácticas de administración.

## Objetivos

- Identificar los elementos principales que se pueden configurar en un SGBD.
- Configurar los parámetros básicos del servidor y de las conexiones.
- Crear y preparar bases de datos para su utilización.
- Comprender la relación entre configuración, seguridad y rendimiento.
- Aplicar criterios básicos de disponibilidad, mantenimiento y recuperación.

## Criterios de evaluación

Se valorará la capacidad para configurar el servidor, establecer conexiones y justificar los parámetros elegidos según las necesidades del entorno.
