# UD 3: Usuarios y permisos

## Introducción a la unidad

En esta unidad se estudia la administración de identidades, roles y permisos para controlar el acceso a las bases de datos y proteger la información.

## Índice de contenidos

0. [Introducción a usuarios y permisos](00-introduccion.md)
	* Usuarios y cuentas de acceso.
	* Roles y grupos de usuarios.
	* Privilegios sobre bases de datos y objetos.
	* Autenticación y autorización.
	* Control de acceso mediante permisos.
	* Principio de mínimo privilegio.
	* Auditoría y revisión de accesos.

## Objetivos

- Crear y gestionar usuarios y roles.
- Asignar, revisar y revocar permisos.
- Aplicar políticas básicas de autenticación.
- Proteger los objetos y datos del SGBD.
- Detectar configuraciones de acceso innecesariamente permisivas.

## Criterios de evaluación

Se valorará la correcta aplicación del principio de mínimo privilegio y la capacidad para documentar los accesos autorizados.
