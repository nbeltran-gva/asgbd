# UD 6: Bases de datos distribuidas

## Introducción a la unidad

En esta unidad se estudian las bases de datos distribuidas, en las que la información y su procesamiento pueden repartirse entre varios servidores o nodos conectados por una red.

## Índice de contenidos

0. [Introducción a las bases de datos distribuidas](00-introduccion.md)
	* Características de los sistemas distribuidos.
	* Arquitecturas y modelos de distribución.
	* Fragmentación y partición de datos.
	* Replicación y sincronización.
	* Transparencia de localización y acceso.
	* Disponibilidad, escalabilidad y tolerancia a fallos.
	* Ventajas, limitaciones y casos de uso.

## Contenidos
- Bases de datos distribuidas.
- Tipos de SGBD distribuidos.
-  Componentes de un SGBD distribuido.
-  Técnicas de fragmentación.
-  Técnicas de asignación.
- Consulta distribuida.
-  Transacciones distribuidas.
-  Optimización de consultas sobre bases de datos distribuidas.
- Replicación.
-  Configuración del «nodo maestro» y los «nodos esclavos».

## Objetivos

- Comprender los principios de distribución de datos.
- Diferenciar fragmentación, partición y replicación.
- Analizar las ventajas y limitaciones de una arquitectura distribuida.
- Identificar problemas de consistencia y disponibilidad.
- Valorar soluciones distribuidas según los requisitos del sistema.


## Criterios de evaluación

La unidad desarrolla el RA6: Implementa sistemas gestores de bases de datos distribuidas analizando sus características y las técnicas de distribución.

a) Se ha reconocido la utilidad de las bases de datos distribuidas
b) Se han descrito las distintas políticas de fragmentación de la información.
c) Se ha implantado una base de datos distribuida homogénea.
d) Se ha creado una base de datos distribuida mediante la integración de un conjunto de bases de datos
preexistentes.
e) Se ha configurado un «nodo» maestro y varios «esclavos» para llevar a cabo la replicación del primero.
f) Se ha configurado un sistema de replicación en cadena.
g) Se ha comprobado el efecto de la parada de determinados nodos sobre los sistemas distribuidos y replicados.
