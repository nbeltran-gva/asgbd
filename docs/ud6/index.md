# UD 6: Bases de datos distribuidas

## Introducción a la unidad

En esta unidad se estudian las bases de datos distribuidas, en las que la información y su procesamiento pueden repartirse entre varios servidores o nodos conectados por una red.

## Índice de contenidos

0. [Introducción a las bases de datos distribuidas](00-introduccion.md)
	* Características de los sistemas distribuidos.
	* Arquitecturas y modelos de distribución.
	* Fragmentación y partición de datos.
	* Replicación y sincronización.
	* Transparencia de localización y acceso.
	* Disponibilidad, escalabilidad y tolerancia a fallos.
	* Ventajas, limitaciones y casos de uso.

## Objetivos

- Comprender los principios de distribución de datos.
- Diferenciar fragmentación, partición y replicación.
- Analizar las ventajas y limitaciones de una arquitectura distribuida.
- Identificar problemas de consistencia y disponibilidad.
- Valorar soluciones distribuidas según los requisitos del sistema.

## Criterios de evaluación

Se valorará la capacidad para analizar una arquitectura distribuida y justificar las técnicas de distribución elegidas.
